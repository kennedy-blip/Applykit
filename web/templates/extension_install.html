1 Install in Chrome, Brave, Edge or Opera (60 Seconds)

  1. Download the ZIP file above and Extract / Unzip it to a folder on your computer.
  2. Open your browser's Extensions page:
    chrome://extensions brave://extensions edge://extensions
  3. Toggle Developer mode ON (top-right switch).
  4. Click Load unpacked and select the unzipped folder (the folder containing manifest.json).
  5. Refresh this ApplyKit tab once — your login session syncs automatically!

2 Install in Mozilla Firefox + Manual Token Copy

  1. Download applykit-firefox.zip above (no need to unzip).
  2. Open about:debugging#/runtime/this-firefox in Firefox.
  3. Click Load Temporary Add-on... and select applykit-firefox.zip.
